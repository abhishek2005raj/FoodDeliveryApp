# FoodExpress

Frontend-only food ordering web application built with HTML, CSS and JavaScript.

## Authentication
- Sign Up / Register
- Login
- Logout
- Client-side validation
- User data stored in LocalStorage
- Login session stored in LocalStorage

> This is a frontend demonstration. LocalStorage authentication is not secure enough for production; a real application should use a backend and secure authentication.

## Main Features
- Food menu
- Search
- Cart management
- Address form
- Checkout
- Order confirmation
- Frontend authentication
